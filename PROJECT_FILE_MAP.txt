1. PROJECT ROOT FILES
--------------------------------------------------------------------------------

pom.xml
    Maven build definition. Declares the artifact
    (com.finance:offline-finance-manager:1.0.0), Java 17 release level, the main
    class (com.finance.app.OfflineFinanceApplication), and every dependency:
    Spring Web / Data JPA / Security / Thymeleaf / Validation, SQLite JDBC,
    hibernate-community-dialects, OpenCV, Tess4J, Apache POI (+ooxml), PDFBox,
    Lombok, commons-codec, WebJars (Bootstrap 5.3.3, Font Awesome 6.5.2),
    DevTools, and the test starters.

README.md
    The single project README: features, requirements, build/run, credentials,
    route tour, data layout, configuration, backups, security, structure,
    testing, troubleshooting, limitations.

run.bat
    Windows one-command launcher. Verifies Java + Maven, creates data/ and
    logs/, kills any running FinWise JAR, runs `mvn clean install -DskipTests`,
    waits for target/offline-finance-manager-1.0.0.jar, starts it on port 8080
    and opens the browser once the port accepts connections.

run.sh
    Linux/macOS equivalent of run.bat (checks Java/Maven, creates directories,
    builds, runs the JAR).

fix_mojibake.py
    Maintenance utility. Scans text files for double-encoded UTF-8 ("mojibake",
    e.g. "ðŸ" / "Â©") and rewrites them by reinterpreting the bytes as Latin-1.
    Used to repair corrupted characters in templates, CSS, JSON and logs.

.gitignore
    Ignores target/, IDE folders, data/ (database, uploads, backups), logs/,
    *.log, environment files, and OS files.

PROJECT_FILE_MAP.txt
    This file.

3.1 app/
--------------------------------------------------------------------------------
app/OfflineFinanceApplication.java
    Spring Boot entry point. @EnableScheduling, so backup and recurring
    schedulers run automatically. Boots the embedded Tomcat on port 8080.

3.2 config/
--------------------------------------------------------------------------------
config/SecurityConfig.java
    Spring Security configuration: BCrypt password encoding, the filter chain,
    which URLs are public (login, register, CSS/JS/locales/vendor) and which
    require authentication, CSRF configuration, logout and session handling.

config/WebConfig.java
    WebMvcConfigurer: static resource handlers, view controllers, and any
    additional interceptors/argument resolvers.

config/WebMvcConfig.java
    Companion MVC configuration (interceptor registration and resource
    locations) used alongside WebConfig.

config/AppLockInterceptor.java
    HandlerInterceptor that enforces the local app-lock passcode after login:
    redirects to /app-lock until the passcode is verified for the session.

config/GlobalExceptionHandler.java
    @Controller implementing ErrorController. Renders the custom error page and
    converts unhandled exceptions into friendly responses.

config/ChatbotExceptionHandler.java
    @RestControllerAdvice scoped to com.finance.chatbot. Returns JSON errors for
    the chatbot endpoints.

controller/ImportController.java

    Implements ReportEngine: assembles the data behind reports and exports.

    Implements DocumentUploadService: stores uploads outside the web root under
    data/import-images (or data/uploads) with safe generated filenames.
service/LocalDuplicateDetectionService.java
    Implements DuplicateDetectionService: amount+date+description(+category)
    fingerprinting against existing and already-imported rows.
service/LocalOpenCVPreprocessor.java
    Implements OpenCVPreprocessor: grayscale, resize, denoise, adaptive
    threshold and deskew so OCR accuracy improves.
service/LocalTess4JOcrService.java
    Implements Tess4JOcrService: runs Tess4J with data/tessdata/eng.traineddata
    and returns raw text plus confidence.
service/LocalPDFBoxService.java
    Implements PDFBoxService: extracts per-page text from PDFs.
service/LocalApachePoiService.java
    Implements ApachePoiService: reads .xls/.xlsx cells into rows and writes
    Excel output.

Concrete application services:
service/UserService.java
    User registration, lookup, BCrypt hashing, profile updates, password
    change, account deletion (data cleanup), and default admin bootstrap.
service/AccountService.java
    Account (bank/cash) business rules and balance calculations.
service/IncomeService.java
    Income business rules, filters, summaries, and workbook mirroring.
service/ExpenseService.java
    Expense business rules, filters, summaries, receipt handling.
service/BudgetService.java
    Budget limits, spent calculation, and over/near-limit detection.
service/FinancialGoalService.java
    Goal creation, progress and status transitions.
service/AppLockService.java
    Stores and verifies the BCrypt-hashed app-lock passcode in the session.
service/ChatHistoryService.java
    Persists and retrieves chatbot conversations per user.
service/CashFlowForecastService.java
    Builds the cash-flow forecast shown on the dashboard/analytics (upcoming
    bills, projected balance, alerts).
service/TransactionExtractor.java
    Turns raw OCR/PDF/CSV text into structured transactions using
    ScanTransactionParser.
service/ScanTransactionParser.java
    Regex/heuristic parser: amounts, dates, merchants, categories from OCR
    text.
service/ImportFileService.java
    Validates uploaded import files (type, size, extension) and hands them to
    the document processor.
service/ImportCommitService.java
    Commits validated import rows as real expenses/incomes in one transaction,
    recording import history and duplicates.
service/UserDataExportService.java
    Full user data export (JSON/CSV) for portability.
service/RecurringTransactionScheduler.java
    @Scheduled daily job that materialises due recurring income/expenses into
    real records exactly once per due date.

    @ConditionalOnProperty(app.backup.enabled) scheduled daily job (02:00 by
