FINWISE PROJECT - OPEN EACH FOLDER AND EXPLAIN ITS CONTENTS
==========================================================

This guide follows the VS Code Explorer like this:
  1. Start at the javaproject folder.
  2. Open the first folder.
  3. Explain its child folders and files. If a child is a folder, open it and
     explain its contents before returning to the parent folder.
  4. Then move to the next folder or file.

Backslash (\) means "inside this folder". Example:
  .github\modernize\java-upgrade\hooks\scripts\
means open .github, then modernize, then java-upgrade, then hooks, then
scripts.

JAVAPROJECT\
============
This is the main project folder. It contains the source code, setup guides,
launch scripts, local data, and files Maven uses to build FinWise.

FOLDERS (OPENED ONE AT A TIME)
------------------------------

.git\
  Hidden Git bookkeeping folder. Git uses it to remember project history and
  changes. Do not edit its internal files manually.

.github\
  GitHub-related settings and helpers. Open its folders in this order:

  modernize\
    Files for optional Java upgrade tooling.

    java-upgrade\
      Optional Java-upgrade helper configuration.

      hooks\
        Scripts that can be called by the Java-upgrade tooling.

        scripts\
          recordToolUse.ps1
            PowerShell helper for recording Java-upgrade tool use.
          recordToolUse.sh
            Shell helper for recording Java-upgrade tool use.

      .gitignore
        Tells Git which generated files in this helper folder to ignore.

.vscode\
  Optional Visual Studio Code project settings.
  extensions.json recommends editor extensions.
  settings.json contains editor settings for this project.

C\
  Old helper scripts; they are not needed to build or run FinWise.
  tmp_pom.bat searches an old computer-specific pom.xml path.
  tmp_pom2.bat prints selected Maven settings from that old path.

data\
  Local application data. It can contain personal finance records and files.
  Protect this folder; do not casually delete or share it.

  backups\
    Application backup files and the local .backup.key file used by some
    backups. Keep the key safe if you need to restore those backups.

  finance-plus\
    Local files belonging to the Finance Plus feature.

    backups\
      Encrypted Finance Plus backup files.

  import-images\
    Images uploaded during document imports. Database records refer to them.

  tessdata\
    Local OCR language data used to recognize text in documents.

  uploads\
    User-uploaded files stored outside the public web pages.

    profile\
      Profile picture image files.

  finance.db
    Main SQLite database containing core application records.

  finance-e2e.db
    Database used for end-to-end testing, not ordinary user data.

  Financial Planning records and uploaded documents are stored in finance.db.
  Documents are private to their account in the application, but the live
  SQLite database itself is not encrypted.

  Finwise_Data.xlsx
    Local Excel workbook used by workbook-based application features.

  Other files in these data folders
    Names and numbers vary as the app is used. They are runtime records,
    images, keys, or backups, not Java source files. Stop FinWise before
    manually copying these files.

HOW THE PROJECT RUNS
--------------------
1. Run run.bat on Windows or run.sh on macOS/Linux.
2. Maven reads pom.xml and builds the Java application.
3. Java starts a local web server.
4. Open http://localhost:8080 in a browser.
5. Browser pages come from src\main\resources\templates\ and use files from
   src\main\resources\static\.
6. Java controllers receive requests and call services to do the work.
7. Services use repositories to save and read records in data\finance.db.
8. Some features also use data\Finwise_Data.xlsx and other folders under data\.

Protect the data\ folder because it can contain private financial details.
Stop FinWise before manually copying its data.
